# telegram

**Назначение:** Боты для уведомлений и диагностики.

**Документы:** ТЗ §4.4; Архитектура §9; ADR-0011.

`python -m apps.telegram.bot` запускает `@reiscontrol_bot` для команды `/start`.
Бот отвечает ID чата. Администратор связывает его с действующим аккаунтом логиста:

```powershell
python -m apps.telegram.subscribe <user_uuid> <chat_id>
```

Сквозные уведомления отправляет `python -m backend.apps.worker.outbox`. Воркер
проверяет подписку и актуальный доступ логиста к клиенту или рейсу перед каждой
отправкой. Для отключения подписки используется `--disable`.

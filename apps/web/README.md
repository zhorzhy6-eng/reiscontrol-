# web

**Назначение:** Веб-кабинет логиста на React, TypeScript и Vite.

**Документы:** ТЗ §4.3; Архитектура §10.

## Разработка

`npm ci`, затем `npm run dev`. Vite передаёт `/api` на локальный backend
`http://127.0.0.1:8000`. Для сборки и проверки: `npm run build`, `npm test`,
`npm run lint`, `npm run format:check`.

Кабинет использует общий API: вход с платформой `web`, список заявок, карточку
рейса и ленту принятых событий. Токен доступа живёт только в текущей сессии
браузера; ID устройства сохраняется между сессиями для привязки токена.

# Android-клиент этапа 1

Kotlin/Compose, minSdk 26, compileSdk 35. `:app` связывает экраны, Room и WorkManager. Типы событий и чек-листы загружаются из неизменяемого снимка рейса; клиент не содержит списка кодов событий.

## Сценарий

После первого входа водитель отдельно принимает политику ПДн и согласие на геолокацию. Версия и ссылки находятся в `config/policies/stage1.properties`; URL пока являются утверждёнными заглушками. После согласий водитель открывает заявку и начинает рейс. Экран рейса строит действия из `config_snapshots`: фото-события для каждого автомобиля и гео-события для точек маршрута. Камера и галерея передают изображение в `WatermarkProcessor`; готовый JPEG, SHA-256 и метаданные сохраняются локально. Событие атомарно попадает в Room и outbox. `SyncWorker` с сетевым ограничением загружает файл по presigned URL, подтверждает вложение и отправляет событие с `Idempotency-Key = client_event_id`. Повторы сохраняют исходный ID.

Локальные черновики и очередь остаются после перезапуска. При выходе из аккаунта приложение не стирает неотправленные факты. Геопозиция запрашивается однократно при создании события через `LocationProvider`; постоянный трекинг не запускается.

## Сборка и проверки

Нужны JDK 17 и Android SDK Platform 35 с Build Tools 35.0.0. Из этого каталога:

```bash
bash ./gradlew ktlintCheck testDebugUnitTest :core:common:test :core:rules:test :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Debug-сборка обращается к `http://10.0.2.2:8000/api/v1/` в эмуляторе. Адрес production API задаётся через `API_BASE_URL` в `app/build.gradle.kts` до выпуска; примерный домен не предназначен для реального подключения.

## Модули

- `core:database`, `core:sync` — локальные факты, вложения, outbox и отправка.
- `core:network`, `core:security` — HTTP-заголовки, токены и привязка устройства.
- `core:location`, `core:camera`, `core:media` — GPS, съёмка и водяной знак.
- `core:config`, `core:rules` — интерпретация снимка и локальная проверка шагов.
- `core:logging`, `core:design`, `core:common` — безопасные логи, UI и общие типы.
- `feature:*` — экраны входа, заявок, рейса, события, чек-листа, завершения, диагностики и настроек.

Полевой тест камеры, галереи, GPS и обрывов сети требует устройства или эмулятора и работающих API, PostgreSQL и Object Storage.

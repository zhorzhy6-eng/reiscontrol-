# core/sync

WorkManager отправляет локальные события и вложения при появлении сети. `TrackingWorker` раз в 15 минут получает одну точку через `LocationProvider` только при активном рейсе, действующем согласии `tracking` и фоновом разрешении Android. Точки сохраняются в Room до отправки. `SyncWorker` отправляет их через `/location/tracks` и сохраняет состояние доставки.

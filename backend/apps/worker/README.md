# worker

**Назначение:** Фоновые обработчики очереди.

**Документы:** Архитектура §4.2, §9.3; ADR-0006.

`python -m backend.apps.worker.outbox` читает принятые события из PostgreSQL
outbox и доставляет уведомления в Telegram только включённым подпискам логистов
с актуальным RBAC-доступом. При сбоях использует lease и backoff; доставленные
адресаты записаны в `notification_log` и пропускаются на следующей попытке.

`python -m backend.apps.worker.devbot` отправляет в отдельный чат разработчика
только машинные коды ошибок, прошедшие проверку `/logs`. Токен и ID чата
передаются окружением из Lockbox.

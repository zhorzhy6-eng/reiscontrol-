# Политики этапа 1

`stage1.properties` содержит утверждённую версию `1.0` и URL политик. Ссылки ведут на домен-заглушку и должны быть заменены на опубликованные документы до пилота. Согласия `pd`, `geo` и `tracking` клиент запрашивает отдельно при первом входе через `/api/v1/me/consents`. Трекинг выполняется только во время активного рейса.

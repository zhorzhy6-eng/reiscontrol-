# Инфраструктура

`terraform/modules/` содержит пустые модули для PostgreSQL, Object Storage, очереди и Lockbox. Они не создают ресурсы и не предназначены для `terraform apply`: параметры сети, окружений, аккаунта Yandex Cloud и политики доступа ещё не утверждены.

Ожидаемый поток этапа 1: API и worker работают с PostgreSQL; клиент загружает фото по короткому presigned URL в Object Storage; транзакционный outbox создаёт задания для Telegram. YMQ и Lockbox остаются инфраструктурными адаптерами для следующего развёртывания. В dev секреты приходят из `.env`, в облаке должны поступать из Lockbox (ADR-0009).

Данные и резервные копии размещаются в российском регионе Yandex Cloud согласно ADR-0010. Для реального развёртывания потребуются отдельные входные параметры и проверка политики доступа и стоимости.

# Инфраструктура

Локальная инфраструктура запускается через [docker-compose.yml](../docker-compose.yml): PostgreSQL 16 и MinIO с постоянными volumes. API, воркеры, Telegram-боты и веб-кабинет запускаются на компьютере по [корневой инструкции](../README.md).

`terraform/modules/` содержит исторические пустые шаблоны и не используется для локального запуска или развёртывания на своём сервере. Не выполняйте `terraform apply` для этих модулей.

Перенос БД и объектов на свой сервер описан в [документе миграции](../docs/migration-to-server.md).

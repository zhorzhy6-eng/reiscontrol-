# ADR-0010. Обработка персональных данных и 152-ФЗ

**Статус:** Принято
**Дата:** 02.10.2026
**Заменяет:** —
**Заменён на:** —

---

## Контекст

ТЗ п. 5.5: устройства водителей — корпоративные или личные.
ТЗ п. 4.1: приложение записывает **координаты** и **время** каждого события.
ТЗ п. 9: всё в Yandex Cloud, данные в РФ.

**Дополнительно (решение заказчика от 02.10.2026):**
- Android — основной клиент на старте.
- iOS — закладывается сразу.
- ГЛОНАСС-трекинг (периодический) — бесплатными методами.
- **Галерея разрешена** как альтернативный способ загрузки фото.

Приложение обрабатывает **персональные данные** водителей:
- ФИО, номер ВУ, телефон;
- геолокация (координаты каждого события + периодический трекинг);
- фотографии;
- идентификатор устройства.

**Важно:** периодический трекинг увеличивает объём обрабатываемых ПДн. Требуется отдельное согласие.

---

## Решение

### 1. Согласие водителя

- При **первом входе** — экран с политикой и согласием на обработку ПДн.
- Согласие **явное**: галочка «Я согласен», без предустановленной.
- Без согласия — приложение не работает.
- Согласие **логируется**: дата, версия политики, IP, `user_id`, платформа (`android` / `ios`).
- **Отдельное согласие на геолокацию** — обязательно.
- **Отдельное согласие на периодический трекинг** — обязательно.
- Согласие можно **отозвать** через настройки приложения.

### 2. Уведомление РКН

- **Заказчик** — оператор ПДн.
- **Исполнитель** — обработчик по поручению.
- **Заказчик** подаёт уведомление в Роскомнадзор **до старта пилота**.
- **Исполнитель** предоставляет данные: категории ПДн, цели, способы, сроки.

### 3. Хранение в РФ

- Все данные — в **Yandex Cloud** (регион РФ).
- **Никакой передачи данных за пределы РФ** без отдельного согласования.
- **iOS-специфика:** Apple может запрашивать данные для аналитики. Отключить в настройках приложения.

### 4. Минимизация

- ФИО, телефон, номер ВУ — для идентификации.
- Геолокация — **при событии** + **периодический трекинг** (интервал 15 минут).
- Фото — только по чек-листу.
- **Никакого доступа к контактам, SMS, звонкам.**
- **Доступ к галерее** — только к **выбранному** файлу. Остальная галерея не читается.
- **Трекинг только во время рейса.** Вне рейса — выключен.

### 5. Сроки хранения

- **ПДн водителя** — пока работает в компании + 1 год.
- **События рейса и фото** — 1 год.
- **Треки** — 1 год.
- **Логи** — 1 год.
- **Аудит** — 3 года.
- После истечения — **обезличивание**.

### 6. Права субъекта

- **Доступ:** через логиста.
- **Исправление:** через логиста.
- **Удаление:** после увольнения (с учётом доказательной базы).
- **Отзыв согласия:** через настройки приложения.
- **Отзыв согласия на трекинг:** отдельно.
- **При отзыве согласия:** блокировать доступ к рейсам, данные не удалять. При повторном согласии — доступ восстанавливается.

### 7. Фото в Telegram

- **Решение заказчика:** отправлять **сами фото** в Telegram.
- **Согласовано с юристом заказчика.**
- **Риск по 152-ФЗ принят заказчиком.**
- **Ответственность за риск — на заказчике.**

### 8. Галерея и ПДн

- При загрузке фото из галереи приложение запрашивает **только выбранный файл**.
- Доступ к остальной галерее **не запрашивается**.
- Это соответствует принципу минимизации (152-ФЗ).
- В метаданных фиксируется только источник: `camera` / `gallery`.

### 9. Шифрование

- **В покое:** PostgreSQL, Object Storage, бэкапы — managed-шифрование (стандартное).
- **В транспорте:** HTTPS, TLS 1.2+.
- **На клиенте:**
  - Android: EncryptedSharedPreferences.
  - iOS: Keychain (позже).

### 10. Логи и ПДн

- В логи **не пишем** полные ПДн.
- В логи **не пишем** координаты без необходимости.
- В логи пишем только `user_id`.
- Логи структурированы (см. ADR-0011).

### 11. iOS-специфика

- **App Tracking Transparency** — отключён (не отслеживаем).
- **NSLocationAlwaysAndWhenInUseUsageDescription** — обязательное описание в Info.plist.
- **NSPhotoLibraryUsageDescription** — обязательное описание для доступа к галерее.
- **Фоновый трекинг** — через `BGTaskScheduler`, только во время рейса.
- **Данные не уходят в Apple** (кроме Crashlytics, если подключён).

### 12. Оператор ПДн

- **Оператор ПДн — заказчик** (транспортная компания).
- **Исполнитель** — обработчик по поручению.
- **Уведомление РКН** — подаёт заказчик.
- **Политика конфиденциальности** — оформляет заказчик. Исполнитель готовит черновик.
- **Юридическое согласование** — юрист заказчика.

---

## Обоснование

- 152-ФЗ — обязательное требование.
- Хранение в РФ — требование 152-ФЗ.
- Периодический трекинг — новые ПДн, требуется отдельное согласие.
- iOS-специфика — требования Apple.
- Оператор ПДн — заказчик, потому что он нанимает водителей и решает, зачем собирать данные.
- Галерея — доступ только к выбранному файлу, минимизация соблюдена.

---

## Последствия

- Экран согласия при первом входе.
- **Отдельный экран согласия на геолокацию.**
- **Отдельный экран согласия на трекинг.**
- Таблица `user_consents` (с полями `platform`, `consent_type`).
- Заказчик подаёт уведомление РКН до старта пилота.
- Политика конфиденциальности (заказчик).
- Порядок удаления данных.
- Telegram-бот шлёт фото (по решению заказчика).
- iOS: `Info.plist` с описаниями разрешений (геолокация + галерея).

---

## Влияние на обновляемость

**Не требует релиза APK/IPA:**
- Изменение политики конфиденциальности.
- Изменение сроков хранения.
- Изменение порядка удаления.
- Изменение правил логирования.

**Требует релиза APK/IPA:**
- Изменение экрана согласия.
- Изменение способа получения согласия.
- Изменение способа отзыва.
- Изменение состава собираемых ПДн.
- Реализация iOS-клиента.

## Открытые вопросы

1. Кто оператор ПДн?
   **Ответ:** Заказчик — оператор, исполнитель — обработчик.

2. Кто подаёт уведомление РКН и когда?
   **Ответ:** Заказчик, до старта пилота.

3. Срок хранения фото?
   **Ответ:** 1 год.

4. Срок хранения треков?
   **Ответ:** 1 год.

5. Срок хранения ПДн водителя?
   **Ответ:** Пока работает в компании + 1 год.

6. Что делать после истечения срока?
   **Ответ:** Обезличивать.

7. Что делать с фото в Telegram?
   **Ответ:** Сами фото. Согласовано с юристом заказчика.
   Риск по 152-ФЗ принят заказчиком.

8. Устройства водителей?
   **Ответ:** Личные.

9. Нужно ли согласие на геолокацию отдельно?
   **Ответ:** Да, отдельное согласие.

10. Нужно ли согласие на периодический трекинг отдельно?
    **Ответ:** Да, отдельное согласие.

11. Кто оформляет политику конфиденциальности?
    **Ответ:** Заказчик (оператор ПДн). Исполнитель готовит черновик.
    Юрист заказчика согласовывает.

12. Что делать при отзыве согласия?
    **Ответ:** Блокировать доступ к рейсам. Данные не удалять.
    При повторном согласии — доступ восстанавливается.

13. Где хранятся данные?
    **Ответ:** Yandex Cloud (регион РФ).

14. Передаются ли данные за рубеж?
    **Ответ:** Да, в Telegram (фото). Согласовано с юристом.
    Риск принят заказчиком.

15. Галерея разрешена?
    **Ответ:** Да. Доступ только к выбранному файлу.
    Минимизация соблюдена.

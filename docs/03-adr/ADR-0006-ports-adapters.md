## Контекст

ТЗ п. 4.1 требует работы **без Google Play Services** (Huawei). Стек (п. 9) предлагает `FusedLocationProvider` (GMS) — противоречие.

ТЗ п. 6.2 требует:
- добавлять новые каналы уведомлений и новые интеграции **без переписывания системы**;
- масштабировать систему при росте числа рейсов, водителей и объёмов фото.

ТЗ п. 16 (следующие этапы) предполагает:
- интеграцию с ЭТрН;
- сканер документов (ML Kit);
- PDF-акт;
- интеграцию с 1С;
- публикацию в RuStore.

**Дополнительно (решение заказчика от 02.10.2026):**
- Android — основной клиент на старте.
- iOS — закладывается сразу, реализуется позже.
- RuStore — канал обновления для Android.
- ГЛОНАСС-трекинг (периодический) — бесплатными методами.

## Решение

Все внешние зависимости — за **интерфейсами (портами)**.

### Порт `LocationProvider`

| Реализация | Платформа | Устройства |
|---|---|---|
| `GmsLocationProvider` | Android | Samsung, Xiaomi, Realme, Honor с GMS |
| `HmsLocationProvider` | Android | Huawei с HMS |
| `PlatformLocationProvider` | Android | универсальный fallback (Android LocationManager) |
| `IosLocationProvider` | iOS | Core Location (позже) |

**Методы порта:**
- `getOneShotLocation(timeoutSeconds: Int): Location?` — одна точка (используется при событии).
- `startPeriodicTracking(intervalMinutes: Int): Flow<Location>` — периодический трекинг (ГЛОНАСС-аналог).
- `stopPeriodicTracking()` — остановка.
- `getAccuracy(): Int` — точность последней точки.

### Порт `NotificationChannel`

| Реализация | Платформа |
|---|---|
| `TelegramChannel` | сервер |
| `SmsChannel` | сервер |
| `EmailChannel` | сервер |
| `WebPushChannel` | сервер |
| `ApnsChannel` | iOS (позже) |
| `FcmChannel` | Android |

### Порт `UpdateChannel`

| Реализация | Платформа | Назначение |
|---|---|---|
| `DirectApkChannel` | Android | APK напрямую (Object Storage) |
| `RuStoreChannel` | Android | RuStore (позже) |
| `TestFlightChannel` | iOS | TestFlight (позже) |
| `AppStoreChannel` | iOS | App Store / Enterprise (позже) |

### Порт `StorageAdapter`

| Реализация | Назначение |
|---|---|
| `YandexObjectStorage` | Основное хранилище |

### Порт `IntegrationPort`

| Реализация | Назначение |
|---|---|
| `EtrnIntegration` | ЭТрН (этап 16) |
| `OneCIntegration` | 1С (этап 16) |
| `MlKitScanner` | Сканер документов (этап 16) |

### Порт `CameraPort`

| Реализация | Платформа |
|---|---|
| `CameraXCamera` | Android |
| `AvFoundationCamera` | iOS (позже) |

## Обоснование

- Прямое использование `FusedLocationProvider` сломает Huawei без GMS.
- Прямое использование Telegram Bot API сделает уведомления единственной точкой отказа.
- Новые каналы и интеграции должны добавляться без правок ядра.
- Заложить iOS, RuStore и ГЛОНАСС сейчас — бесплатно. Добавлять позже — дорого.
- Периодический трекинг через `WorkManager` (Android) и `BGTaskScheduler` (iOS) — бесплатные методы.

---

## Последствия

- Выбор реализации `LocationProvider` — на старте приложения (по `BuildConfig`).
- Новый канал = новый адаптер, без правок бизнес-логики.
- Тестирование каждой реализации — на реальных устройствах (Xiaomi, Samsung, Huawei, Honor, Realme, iPhone).
- Веб-кабинет обязан показывать события независимо от Telegram.
- Периодический трекинг — через `WorkManager` с интервалом 15 минут (минимум по Android).
- iOS-трекинг — через `BGTaskScheduler` (позже).

## Влияние на обновляемость

**Не требует релиза APK/IPA:**
- Добавление нового канала уведомлений на сервере (SMS, e-mail).
- Добавление новой интеграции на сервере (1С).
- Изменение шаблонов уведомлений (через `notification_templates`).
- Изменение политики ретраев.
- Изменение интервала периодического трекинга (если в разумных пределах).
- Добавление `RuStoreChannel` (когда RuStore появится).

**Требует релиза APK/IPA:**
- Добавление новой реализации `LocationProvider` на клиенте.
- Добавление нового `UpdateChannel` на клиенте.
- Изменение `CameraPort`.
- Интеграция с ML Kit (этап 16).
- Реализация iOS-клиента (новый IPA).

**Правило:** серверные адаптеры — без релиза. Клиентские адаптеры — с релизом.

## Открытые вопросы

1. Какие устройства в пилоте? Xiaomi, Samsung, Huawei, Honor, Realme, iPhone?
   **Ответ:** Android: Xiaomi, Samsung, Huawei, Honor, Realme. iOS — позже.

2. Какой интервал периодического трекинга считать оптимальным?
   **Ответ:** 15 минут (минимум Android для WorkManager).

3. Нужен ли трекинг в фоне при выключенном экране?
   **Ответ:** Да, через foreground service с уведомлением.
